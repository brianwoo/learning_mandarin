The key sentence structure for this lesson is: “为什么河水会流动？” (Why does the river water flow?). This is a sentence used to ask about reasons and causes using “为什么” (why). The structure is: 为什么 + subject + verb + object?


Please note that the subject and “为什么” can switch places without changing the meaning. We will practice this structure more in the next lesson.
